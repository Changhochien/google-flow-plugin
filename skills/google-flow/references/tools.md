# 2.5D, Multi-Angle & Scene Exploration (`Tools`)

1. Open **`Tools`** in the left `Project navigation` sidebar (`/project/<uuid>/tools`, visible at `>= 1280px` viewport) and browse **`Templates`** or **`Community`** (or build one via **`Create tool`**—check displayed credit cost first):
   - **2.5D / 3D & Camera:** `DepthWarp 4D`, `3D Model Visualizer`, `Scout360`, `Frame Deconstructor`, `Director Camera & Path Vector Board`.
   - **Scene & Shot Exploration:** `Scene Explorer`, `Shot Explorer`, `Storyboard Studio`, `Mockup`, `LuzRelighting`.
2. Open the tool, feed in a project image or prompt, confirm credits if > `0`, run it, and save/use the output as an `Ingredient`.
   - **Sandbox & credits:** Tool UIs render inside cross-site `*.scf.usercontent.goog` iframes blocked to the browser subagent (`NAVIGATION_BLOCKED`) and warn that they may consume credits—have the user open and run Tools (e.g., `Scout360`, `Scene Explorer`) directly in the browser pane.
